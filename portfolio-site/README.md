# Tanay Gaykwad — portfolio landing page

A static, responsive one-page portfolio for the ReliefTrail projects. It uses plain HTML and CSS, has no build step, and links directly to the public GitHub repositories. Current statuses are stated honestly: ResponseHub is a local portfolio demo and ReliefTrail Blockchain has no verified public testnet deployment.

Open `index.html` locally, or publish this directory through GitHub Pages after selecting **GitHub Actions** as the Pages build source in repository settings. A live URL should only be added to the project cards after the page and each linked project demo are actually deployed and verified. The contact link currently points to the public GitHub profile; add another public contact method only if desired.
